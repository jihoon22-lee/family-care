# ADR 0004: Evidence-first tri-state decisions

- Status: Accepted
- Date: 2026-08-23

## Context

보험 지급 조건은 실제 가입 여부, 사건일 계약 상태, 약관 정의, 면책, 횟수 이력에 의존합니다. 정보 부족을 false로 취급하면 청구 기회를 놓치고, true로 추정하면 지급 가능성을 과장합니다. AI 자연어 답변만으로는 재현성과 근거 추적이 부족합니다.

## Decision

모든 핵심 조건은 `MATCH`, `NO_MATCH`, `UNKNOWN`으로 평가합니다. 실제 가입 Rider를 증권에서 먼저 확인하고, 판정에는 증권과 약관 페이지 Evidence를 연결합니다. 정보 부족과 상태 미확인은 `UNKNOWN`이며 선택형 추가 질문을 만듭니다.

정액형 계산은 명시적 수식으로, 실손형은 필요한 비용 자료가 있을 때만 처리합니다. AI는 구조화와 설명만 보조하고 규칙 결과를 덮어쓰지 않습니다.

## Alternatives

### Binary true/false

단순하지만 정보 부족과 명확한 불일치를 구분하지 못합니다.

### Probability score

정렬에는 편리하지만 보정 데이터 없이 숫자가 과도한 확신을 줄 수 있고 근거를 숨깁니다.

### LLM-only answer

빠른 프로토타입은 가능하지만 계약 버전, 계산, 재현성, 면책 처리의 권위 경계가 없습니다.

## Consequences

- UI가 미확인 조건과 제외 근거를 명시해야 합니다.
- 규칙별 Evidence와 버전을 저장해야 합니다.
- 사용자는 추가 질문을 생략하고 현재 후보를 볼 수 있습니다.
- 지급 확정 대신 청구 검토 후보라는 표현을 유지합니다.
