# FamilyCare v0.1.0 verification boundary

이 문서는 `v0.1.0` 태그 전 검증과 완료된 태그 workflow·GHCR·GitHub Release 증거를 분리해 기록한다. `v0.1.0`은 commit `4fff47b41e22eb95fed42887038640fb75e0388a`에서 2026-08-26에 게시됐다. 이 문서는 실제 보험 문서나 개인 데이터를 검증했다는 기록이 아니다.

상태 표기 규칙은 다음과 같다.

- `PASSED`: 해당 경계의 검증이 실행되어 통과했다.
- `FAILED`: 해당 검증이 실행되었으나 실패했거나 차단되었다.
- `UNVERIFIED`: 이 작업 범위에서 실행할 수 없거나 실제 환경 검증이 남아 있다.
- `PENDING`: 태그 생성·게시처럼 아직 수행하지 않은 후속 단계다.

## Release scope

- `v0.1.0`은 GHCR의 Web, API, Worker 세 컨테이너 이미지 게시까지만 포함한다.
- 이미지에는 버전 태그와 commit SHA 태그를 사용하고, 세 이미지의 version/SHA manifest digest가 이미지별로 같은지 확인한다.
- No `latest` tag is produced for this release.
- Cloud Run is outside this release scope.
- GHCR 게시 성공은 운영 배포, 공개 ingress, 데이터베이스 전환 또는 실제 사용자 데이터 검증을 뜻하지 않는다.

### Digest comparison contract

OCI `Docker-Content-Digest` 값은 `sha256:<64 lowercase hexadecimal characters>` 형식이어야 한다. 게시 후 각 이미지의 version reference와 같은 이미지의 commit reference가 가리키는 digest가 일치해야 하며, 다른 이미지의 digest와 비교해 통과시키지 않는다. response body, layer, registry credential은 증거로 저장하지 않는다.

## Private runtime acceptance

합성 Compose 검증과 별도로 개인 WSL runtime에서 다음의 최소 사용 흐름을 확인했다.

- `PASSED`: Docker Compose 서비스가 Web gateway 하나만 외부 진입점으로 제공했다.
- `PASSED`: Tailscale HTTPS 경로로 접근해 앱 login이 성공했다.
- `PASSED`: 인증 후 ledger, document import, claim, clause search, session settings 화면을 탐색하고 logout했다.
- `PASSED`: Worker의 synthetic OpenAI structuring, independent verifier, deterministic validation pipeline이 통과했다.
- `UNVERIFIED`: Windows 브라우저, 모바일 PWA, 다른 실제 기기의 접근은 확인하지 않았다.
- `UNVERIFIED`: 실제 보험 PDF, OCR 결과, 암호화 archive, 실제 보험금 계산 자료는 처리하지 않았다.

이 항목들은 release artifact에 private source, derived text/image, prompt/response, key, session token을 포함하지 않는다. Tailscale 연결은 앱 인증을 대신하지 않으며, provider 성공은 보험 자격이나 지급액 판정을 의미하지 않는다.

## Unverified boundaries

- 실제 보험 문서 및 사용자 입력의 format·password·OCR acceptance
- Windows 실제 브라우저와 모바일 PWA 설치·offline 동작
- 현재 사용하지 않은 다른 기기의 Tailscale HTTPS 접근
- 보험사 제출, 운영 데이터베이스, Cloud Run 또는 public production deployment
- 실제 운영 배포 뒤의 image pull·runtime·traffic 검증
